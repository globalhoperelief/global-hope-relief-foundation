# Security Policy

## Reporting a vulnerability

If you believe you have found a security issue affecting this website, please email:

foundationglobalhoperelief@gmail.com

Please include:
- The page or feature affected
- A clear description of the issue
- Steps to reproduce it, if safe to do so
- The potential impact

Please do not publish private information, attempt to access other people's data, disrupt the website, or test the form by sending spam.

## Scope and limitations

This repository contains a static website hosted with GitHub Pages. The public website does not provide user accounts or a payment-processing system. The funding interest form is handled by an external form service; vulnerabilities in that service should be reported to its operator.

## Security practices

Repository maintainers should:
- Enable two-factor authentication on GitHub.
- Use a unique password and store recovery codes securely.
- Review collaborators and repository access regularly.
- Never commit passwords, private keys, API credentials or donor-sensitive data.
- Review changes before publishing them to the live website.
- Keep third-party services and links under periodic review.

This policy is an initial disclosure route, not a guarantee of a formal security response time.
